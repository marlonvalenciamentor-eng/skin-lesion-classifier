Desglose técnico completo de la interfaz

Fuente imprimible de responsabilidades y flujo de integración.

Clasificador de lesiones cutáneasDetalle de componentes del flujo diagnóstico

Esta hoja describe cómo la interfaz recibe entradas, solicita el procesamiento al backend y presenta resultados explicables. El HTML documenta el flujo, pero no ejecuta PyTorch ni Transformers.

Streamlit · capa de presentación

Construye la pantalla, recibe el archivo mediante sus controles y presenta el estado de carga, el resultado y la explicación visual. Esta página HTML solo representa esa interfaz.

Facade · DermatologyDiagnosticFacade

Coordina la interfaz con el backend: recibe la imagen validada, coordina preprocesamiento, inferencia y explicación, y devuelve un resultado documentalmente consumible.

ViTForImageClassification · inferencia

Recibe la imagen preprocesada, produce puntuaciones de clase y permite derivar las probabilidades que Streamlit presenta. El HTML no importa ni ejecuta Transformers.

Grad-CAM · explicación

Usa activaciones y gradientes de una capa del modelo para generar un mapa de atención que la interfaz superpone sobre la imagen. El HTML documenta el flujo, no calcula el mapa.

Encabezado y barra lateral

Streamlit presenta el contexto, el formato admitido, el modelo seleccionado, el dispositivo de inferencia y la disponibilidad de Grad-CAM sin ejecutar lógica de modelo desde esta maqueta.

Carga e imagen de entrada

La interfaz valida JPG/PNG y entrega la imagen a DermatologyDiagnosticFacade. El backend la normaliza para el ViT y devuelve una representación apta para presentar.

Resultados y probabilidades

La interfaz consume el resultado de DermatologyDiagnosticFacade, ordena clases y probabilidades de ViTForImageClassification y presenta una salida orientativa con sus estados.

Flujo de accesibilidad y explicación

Desde la carga hasta la interpretación, la vista conserva nombres accesibles y foco de teclado; Grad-CAM aporta la evidencia visual que acompaña la salida del modelo.
