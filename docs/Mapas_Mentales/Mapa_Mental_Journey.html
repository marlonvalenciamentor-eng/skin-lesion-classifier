Pipeline de datos, arquitectura y entrega

Relación entre el código del clasificador y las decisiones de calidad que acompañan el despliegue.

La arquitectura reúne un pipeline de datos explicable, un entorno reproducible y una ruta CI/CD orientada por especificaciones. Cada artículo presenta una responsabilidad cohesiva y una integración desacoplada.

1. Entorno determinista con uv

Python 3.13 y el lockfile de uv sincronizan dependencias mediante uv sync. uv run pytest y uv run ruff proporcionan comprobaciones repetibles para cada entrega.

2. Pipeline de datos 224x224

src/preprocessing.py valida la imagen, convierte a RGB, redimensiona a 224x224 y aplica la normalización ImageNet para construir el tensor esperado por ViT.

3. Pruebas AAA en PyTest

test_preprocess_img.py organiza Arrange, Act, Assert para verificar dimensiones, canales y valores normalizados. El contrato de tensor queda visible desde la primera etapa.

4. Inferencia ViT y Grad-CAM

El ViT transforma el tensor en logits y probabilidades para HAM10000. Grad-CAM agrega evidencia visual y fortalece la revisión de la decisión del modelo.

5. DermatologyDiagnosticFacade

La Facade coordina validación, preprocesamiento, inferencia y explicación. La UI recibe un resultado cohesivo, mientras cada componente mantiene un acoplamiento bajo.

6. Modularidad y diseño sostenible

Alta cohesión en módulos de datos, modelo, explicabilidad y presentación permite evolución independiente. El flujo modular conecta Streamlit con servicios tipados y responsabilidades claras.

7. CI/CD, empaquetado y Streamlit

El build empaqueta el entorno con uv, el testing valida contratos y staging prueba el Walking Skeleton. El deploy publica una experiencia Streamlit con predicción y Grad-CAM.

8. Shift-Left, SDD y sesgos

La secuencia Explore → Propose → Spec → Implement & Verify convierte Vibe Coding en entregas guiadas. Las pruebas tempranas y la revisión de HAM10000 hacen visibles dimensiones, calidad y sesgos.
